| Токен         | HEX       | Назначение                      |
| -------------- | --------- | ------------------------------- |
| `imo-deep`     | `#051A24` | Тёмный фон (от #005A7F)         |
| `imo-navy`     | `#0A2E3D` | Тёмно-бирюзовый                 |
| `imo-ocean`    | `#0081B4` | Основной синий (брендбук)       |
| `imo-wave`     | `#00A3D7` | Яркий синий (брендбук)          |
| `imo-sky`      | `#00E5FF` | Неон-циан (от #00A2B1)          |
| `imo-foam`     | `#00FFE0` | Неон-бирюза (от #00B09C)        |
| `imo-sand`     | `#E6E1DE` | Светлый (брендбук)              |
| `imo-coral`    | `#00B09C` | Бирюза CTA (брендбук)           |
| `imo-teal`     | `#00A2B1` | Голубой-зелёный                 |
| `imo-green`    | `#00FF41` | Неон-зелёный (от #00BB04)       |
| `imo-neon`     | `#00FFE0` | Основной неон                   |

## Типографика

| Роль              | Шрифт          | Начертание               | Подключение           |
| ----------------- | -------------- | ------------------------ | --------------------- |
| **Заголовки**     | Nasalization   | Regular (uppercase)      | CDN Fonts             |
| **Основной текст**| Ubuntu         | Light 300 / Regular 400 / Medium 500 / Bold 700 | Google Fonts |

- Заголовки (h1–h6) набираются шрифтом **Nasalization**, всегда uppercase, letter-spacing: 0.02em.
- Основной текст — **Ubuntu**, regular 400, line-height 1.6.
- Кавычки: «ёлочки».
- Тире: —.

## CSS-переменные

```css
--font-heading: 'Nasalization', 'Arial Black', sans-serif;
--font-body: 'Ubuntu', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
```

## Tailwind-классы

- `font-heading` — шрифт Nasalization
- `font-body` — шрифт Ubuntu

## Принцип

Цвет = идентификатор направления. Фон = единый тёмный с морской тематикой. Заголовки — крупные, футуристичные (Nasalization). Текст — чёткий и читаемый (Ubuntu).

## Логотип

Логотипы хранятся в `frontend/nextjs/public/logos/`:
- `logo-imo.svg` — основной SVG (белый на тёмном)
- `logo-imo.png` — растровый вариант
- `icon.svg` — иконка

Путь в коде: `/logos/logo-imo.svg`
Использовать белый вариант на тёмном фоне.
