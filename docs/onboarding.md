# Онбординг: как работать с сайтом ИМО (Wagtail)

## Как зайти в админку

1. Откройте адрес CMS (например `https://cms.example.com/admin/` или локально `http://localhost:8000/admin/`).
2. Введите логин и пароль (выдаёт администратор).
3. После входа откроется панель «Wagtail» — разделы «Страницы», «Изображения», «Документы» и т.д.

## Как добавить страницу / раздел

1. В левом меню: **Страницы**.
2. Выберите родительскую страницу (например «Главная»).
3. Нажмите **Дочерняя страница** → выберите тип, например **Страница** (Standard Page).
4. Заполните заголовок, краткое описание (intro), основной текст (body).
5. **Опубликовать** (или «Сохранить черновик»).

## Как добавить новость

1. **Страницы** → найдите раздел **Новости** (News index).
2. **Дочерняя страница** → тип **Новость** (News page).
3. Укажите дату, краткое описание, текст.
4. **Опубликовать**.

## Как менять меню

Меню в Wagtail обычно строится по дереву страниц: отображаются только опубликованные страницы. Чтобы «спрятать» пункт — снимите публикацию или переместите страницу. Если используется отдельный сниппет «Меню» — его правка в разделе **Snippets** (настраивает разработчик).

## Как грузить картинки

1. В левом меню: **Изображения**.
2. **Добавить изображение** → выберите файл.
3. Заполните название (для поиска), при необходимости — теги.
4. В контенте страницы используйте кнопку **Вставить изображение** в редакторе и выберите загруженное.

## Как откатить правку (если сломали)

1. Откройте страницу в админке.
2. Вкладка **История** (если включена) — можно посмотреть старые версии.
3. Если нужно вернуть контент — отредактируйте страницу вручную, вставив сохранённый текст из бэкапа или из истории.
4. При серьёзном сбое — восстановление из бэкапа БД (см. **docs/deploy.md**).
