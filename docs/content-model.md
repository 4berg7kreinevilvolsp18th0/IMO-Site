# Модель контента (типы страниц Wagtail)

Описание типов страниц для сайта Института Мирового Океана (ИМО).

---

## HomePage (Главная)

- **Роль:** корневая страница сайта.
- **Поля:**
  - `title` — заголовок (системное).
  - `intro` — краткое вступление (до 500 символов).
  - `body` — основной текст (rich text).
- **Дочерние типы:** StandardPage, NewsIndexPage.

---

## StandardPage (Обычная страница)

- **Роль:** раздел/подстраница (например «О нас», «Контакты»).
- **Поля:**
  - `title` — заголовок.
  - `intro` — краткое описание (до 500 символов).
  - `body` — основной текст (rich text).
- **Родитель:** только HomePage (или другая страница, если настроено).

---

## NewsIndexPage (Раздел новостей)

- **Роль:** страница-список новостей.
- **Поля:**
  - `title` — заголовок (например «Новости»).
  - `intro` — вступление раздела (rich text, необязательно).
- **Дочерние типы:** только NewsPage.

---

## NewsPage (Новость)

- **Роль:** одна новость.
- **Поля:**
  - `title` — заголовок новости.
  - `date` — дата публикации.
  - `intro` — краткое описание (до 500 символов).
  - `body` — основной текст (rich text).
- **Родитель:** только NewsIndexPage.

---

Для Path B (headless) эти типы отдаются через **Wagtail API v2**:  
`/api/v2/pages/`, фильтр по типу: `?type=news.NewsPage`, `?type=pages.StandardPage` и т.д.
